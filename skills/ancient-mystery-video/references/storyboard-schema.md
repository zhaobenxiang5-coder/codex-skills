# Storyboard schema

Each scene must contain: `id`, `narration`, `keyText`, `claimIds`, `factLevel`, `sourceIds`, `visualPrompt`, `motionPreset`, `image`, `audio`, `subtitles`, `status`.

Use 10-14 scenes. One scene conveys one point. Rotate wide environment, medium archaeology activity, object detail, underground reconstruction, map, and abstract evidence visualization. Keep narration short enough for 4.5-8.5 seconds.
