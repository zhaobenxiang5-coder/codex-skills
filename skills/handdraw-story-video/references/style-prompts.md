# Image generation style profiles

## Shared prompt rules

Always request a 3:4 portrait storybook page on stable warm off-white paper. Keep the upper 24 percent almost empty for narration. Put one isolated narrative subject in the lower area with generous negative space. The default must be a character-only or key-object-only composition: no full environmental background, no dark page, no gradient or vignette. Require natural anatomy, expressive faces, readable silhouettes, consistent recurring characters and unchanged clothing.

Always append:

```text
No written words, no letters, no numbers, no logo, no watermark, no border, no UI, no photorealism, no 3D render.
```

## story-color-sketch

Use for fables, history, knowledge and character stories:

```text
Traditional Chinese colored-pencil storybook illustration, fine graphite outlines, warm muted watercolor-pencil fill, subtle paper grain, restrained earthy palette, simple rural or historical environment, hand-drawn imperfections.
```

## story-pencil

Use for family, emotion and realistic stories:

```text
Emotional graphite-pencil storybook illustration, charcoal-gray contours, soft cross-hatching, restrained muted color accents only on emotional focal points, subtle paper grain, intimate cinematic framing.
```

## Cast reference

Generate a plain reference sheet with front and three-quarter views of all recurring characters. Do not add labels. Leave generous separation between figures so later scenes can use it as a clean image reference.
