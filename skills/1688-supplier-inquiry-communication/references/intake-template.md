# 运行前产品确认模板

只询问当前产品；不填示例参数，不引用历史产品。

## 1. 单项目与输出验收

1. 这次要找什么产品？上传哪些设计图、产品图或参考链接？
2. 最终样品必须实现哪些核心功能？哪些结构不能改？
3. 哪些尺寸、外观、安全或性能是硬性标准？用户收到样品后怎么测试才算通过？
4. 哪些材料、工艺或生产方式可由厂家自行决定？
5. 这个产品属于哪个长期品类赛道？需要哪些关键工艺、材料或设备能力，用于先匹配现有优选/核心工厂？

以上组成 `OutputAcceptanceBrief`，同时用于现货原样可用判断、定制样品交付和最终验收。

## 2. 进入定制时的联系目的与设计模式

6. 请用一句话确认 `contactIntent.coreConcept`：希望厂家配合实现什么核心方向？
7. 设计属于哪一种：
   - `locked-drawing`：图纸结构已锁定，厂家只需按图落地并报告必要调整；
   - `collaborative-design`：允许厂家参与结构方案。
8. 若结构锁定：哪些图纸已批准？哪些结构事实经用户确认、不再向厂家重复提问？

## 3. 部件、材料与规格

9. 产品有哪些稳定部件？逐项记录 `componentKey / label`。
10. 每个部件材料是固定，还是 `supplier-to-propose`？哪些部件属于材料关键项？
11. 用户是否**明确要求**成本型/耐用型对比？默认为否；默认只记录最终样品实际材料。

## 4. 样品、商务与边界

12. 用户是否已有计划采购量？若没有，不得预设；向厂家分别询问MOQ和经济下单量。
13. 目标价格、包装、税运口径和周期是否已有硬要求？
14. 哪些动作必须再次审批：附件、图纸、站外联系、地址、付款、下单、模具、采购承诺？
15. 什么书面证据才可进入打样评估？哪些仍必须样品实测？

整理后输出：

- `confirmed / unknown / supplier_to_propose / forbidden_to_assume`
- `OutputAcceptanceBrief`
- `designIntent / lockedFacts / components`
- 现货原样可用判断和定制供应商准备使用同一项目
- 优先复用老厂的匹配条件、1～3家推荐与缺失证据；新厂在老厂阶段未结束前只读准备
- 首询会问什么、明确不会问什么、哪些图纸事实不重问
- 逐厂首询预览

然后等待用户明确批准。
