# 逆向与安全工程套件 (Reverse Engineering & Security Suite)

本目录为高度集成的安全研发与逆向分析套件，包含 35+ 个专业领域的独立技能：

## 核心子技能列表

| 子技能 | 说明 |
| :--- | :--- |
| `apk-reverse` | Android APK 反编译、签名绕过、Frida Hook 与资源分析 |
| `js-reverse` | 前端 JavaScript 逆向、Webpack 打包分析、加密混淆还原 |
| `browser-extension-reverse` | 浏览器扩展插件解包、权限审计与通信逻辑分析 |
| `ida-reverse` / `ghidra-reverse` | 二进制静态反汇编与动态调试分析 (IDA Pro & Ghidra) |
| `go-rust-reverse` | Go / Rust 现代编译型语言特殊符号还原与分析 |
| `dotnet-reverse` | .NET / C# 程序反编译 (dnSpy / ILSpy) 与补丁制作 |
| `binary-diff` / `patch-diff-exploit` | 二进制补丁比对 (BinDiff) 与 CVE 漏洞补丁分析 |
| `code-audit` | 自动化代码安全审计与常见漏洞模式挖掘 |
| `llm-security` | 大模型提示词注入、越狱防护与模型安全评估 |
| `protocol-reverse` | 私有网络协议抓包、结构还原与通信模拟 |
| `malware-analysis` | 恶意样本特征提取、行为监控与取证分析 |
| `cloud-k8s` | 云原生架构与 Kubernetes 集群安全评估 |
| `pentest-tools` | 常用渗透测试与自动化安全工具链联动 |

## 使用方式
可直接引用对应子目录中的独立 `SKILL.md`，或在本目录整体调度相关逆向工具脚本。
