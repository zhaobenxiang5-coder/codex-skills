# 国外差异化产品参考挖掘

## 目标

建立“产品开发参考模块库”，不是做综合好物榜。候选整款不必完美，但必须提供一个可看见、可命名、可打样的具体答案。

## 开始前

1. 明确品类、目标产品价值和禁区。
2. 读取该品类的历史台账；狗胸背带默认读取 `references/dog-harness-ledger.md`。
3. 用 `scripts/check_ledger.py --ledger references/dog-harness-ledger.md 产品名...` 检查产品是否已采用、已否决、暂缓或已经给过。
4. 再给候选分配机制指纹 ID，并运行 `scripts/check_ledger.py --ledger references/dog-harness-ledger.md --mechanism-id 指纹ID 产品名...`。机制指纹写成 `使用前 → 触发动作/结构 → 使用后结果`，例如“替换饰件 → 插入统一接口 → 改变外观表达”。历史已采用、已否决或暂缓的相同机制，不得换品牌后冒充新品再次交付。
5. 只有机制确实不同，或同一机制出现了新的关键动作，才可以作为延伸候选，并必须主动写明与旧款的差别。

## 产品否决与机制否决必须分开

- 用户说“这款不要、这款不符合”时，只否决这个具体产品，不得自动推断该结构、材料或机制也被否决。
- 用户说“这个机制不要、这个方向以后别找”时，才把机制指纹标为否决。
- 用户否决的原因如果是执行不够好、图片表达弱、证据不足或产品场景不合适，该机制继续保持 `open`，允许寻找更好的代表产品。
- 用户采用了某款，但只作为纯分享时，只记录该产品的分享用途；除非用户明确否决，否则相同机制的成熟商业化产品仍可继续寻找。
- 用户指出“这是重复的”时，回查它重复的是哪个已采用或已否决机制，再占用对应机制指纹，不能仅记录本次产品名。

## 参考价值的四条通道

产品至少命中一条：

1. **新场景**：让产品进入普通同类没有覆盖的真实使用场景。
2. **新动作或交互**：使用前、触发动作、使用后能形成清楚变化。
3. **新结构逻辑**：受力、调节、连接、收纳、换件或组合方式不同。
4. **新材料或表达系统**：材料、五金、纹理、文化图形或可持续方案形成完整产品语言，而非只换颜色。

“透气、反光、软垫、好看、轻量、常规快扣、普通前后牵引环”只能作为辅助买点，不能单独成为入选理由。

## 先看“整款答案”，再看机制新不新

- 不从专利名、材料名或功能词倒推产品；先判断整款是否给出了一个用户一眼能懂的产品答案。
- 做删除测试：拿掉被提炼的模块后，如果它立刻退回普通同类，说明模块可能成立；拿掉后仍只是同一款普通产品换说法，则不成立。
- 做一图一句测试：产品图应能看见差异，一句话应能说清“原来做不到什么 → 触发什么结构/动作 → 现在得到什么结果”。
- 材料创新只有在产生清楚可感知的结果，或形成完整且鲜明的产品表达时才成立；只把稀有材料贴在普通结构上不成立。
- 模块化只有在改变结构、功能、尺码、使用阶段或复购方式时才成立；只换颜色、饰件或装饰面不算新的模块化答案。
- 小细节可以入选，但必须显著改变一次高频动作或解决明确麻烦；“聪明但影响很小”不冒充整款答案。
- 电子、医疗、救援、工作犬及概念产品可以保留给用户判断，但必须单独标明场景和商业化状态，不与普通日常开发款混写。

这是一道定性闸口，不做综合打分，也不代替用户作最终采用决定。

## 两类输出不得混用

1. **开发参考**：能拆成结构、材料、交互或组合模块，能交给工厂找现货或打样。
2. **纯分享/趋势参考**：前沿概念值得展示，但暂时不适合作为找现货或打样答案。

纯分享款要明确写“纯分享，不计入开发参考数量”，不能拿来补足用户要求的开发款数量。用户对某款的采用用途以用户结论为准。

## 搜索顺序

按以下顺序扩池，不只看畅销榜：

1. 当年新品、设计奖、新品展和众筹；
2. 已商业化专利和品牌新品；
3. 各国平台新品榜、飙升榜、愿望榜和类目榜；
4. 独立品牌、区域市场、相邻品类材料与结构；
5. 国内淘宝、天猫、1688进行同结构复核。无法完成登录态搜图时明确写“本轮未完成国内同结构复核”，不得把未核验写成“国内没有”。

优先找官方直达商品页；第三方文章只作补充证据。网页检索结果、品牌宣传、第三方估算和分析推断必须分开。

搜索候选时，先建立较大的产品池，再按“整款答案”收敛。某个具体产品被否决后，继续在其 `open` 机制下寻找执行更强、图片更直观、场景更贴近日常或证据更完整的代表款，不能把同一机制整体封死。

## 单款核验

交付前逐款确认：

- 主体属于目标品类，链接、型号、图片与文字一致；
- 页面当前可打开，并记录在售、预售、众筹结束或缺货状态；
- 创新位于产品本体或明确的整套产品逻辑；
- 去掉营销词后，仍能用一个具体名词短语命名模块；
- 从图片或结构说明能看见差异；
- 工厂可以据此做样，不使用“人体工学、黑科技、款式”等空词替代结构；
- 国内已有成熟同结构时如实说明，但不替用户做最终价值淘汰。

只主动淘汰：错品类、链接错配或失效、完全相同型号重复、伪造产品。其余边界候选保留证据，最终由用户决定。

## 买点提炼

- 买点 A—D 不固定分类，按产品实际图和页面提炼，不强凑四项。
- 先写“结构/材料是什么”，再写“它带来什么动作或表达”。
- `借鉴核心要素`必须是可交给工厂的名词短语，例如“侧向滑移牵引环”“被动通风孔阵列”“木质素生物基壳体”。
- `拿来还是借鉴`写开发动作，例如“借鉴整套车载逻辑”“借鉴单模块”“找相似现货微调”。
- `最终总结`写：找什么现货｜增加或删除什么｜怎样换色品牌化｜先测什么。

## 固定输出格式

每款严格使用以下字段，全部中文；品牌、型号和 URL 保留原文。价格写人民币约价并保留原币。没有销量或趋势证据时字段留空，不写 `unknown`，不编造。

```text
1. 产品名
渠道：
链接：
价格：
销量：
趋势：
核心风格：
买点A：
买点B：
买点C：
买点D：
适合成交方向：
拿来还是借鉴：
借鉴核心要素：
最终总结：
```

## 交付闸口

交付前逐项检查：

- 与历史台账、当前批次去重；
- 完成产品名、同型号和机制指纹三级去重；
- 直达链接真实匹配，不用搜索页冒充商品页；
- “最新”有当年发布、当前在售/预售或近期新品证据；
- 价格、销量、排名只写页面明确显示的事实；
- 每款一句话能说明其独有答案；
- 十款不能靠同一种原理重复凑数；边界款和概念/预生产款必须直说状态，不可包装成成熟在售款；
- 不因 AI 主观不喜欢而隐藏真实候选。

用户确认采用或否决后，及时把产品名、链接、机制和结论写入该品类台账；产品结论和机制结论分别记录，禁止相互代替。
