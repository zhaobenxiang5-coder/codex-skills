# 狗胸背默认规则

## 产品目标

让主人穿脱、使用和携带方便；让狗狗穿着舒适、活动自然，尽量不勒颈和磨腋；提升上狗颜值；让人宠安全、轻松地遛狗。

## 默认商业条件

- 完整胸背或胸背＋牵引绳完整套装的SKU价格必须大于15元。
- MOQ为1。
- 对应SKU页面显示库存大于0。
- 单独项圈、牵引绳、灯、拾便袋、补差价和普通配件不能冒充完整胸背SKU。

## 差异化通道

产品至少贡献一个可见、可命名、可打样的模块：

1. 新场景；
2. 新动作或交互；
3. 新结构逻辑；
4. 完整材料或视觉表达。

普通透气、反光、软垫、轻量、常规快扣、普通前后牵引环、普通提手和单纯换色只能作为辅助卖点。

## 马鞍型试跑默认

目标整款：马鞍型短背胸背。

- 必须：马鞍型短背轮廓、宽背片、双侧快拆。
- 优选：背部宽提手、反光织带、背部金属D环、小物挂点、缓冲牵引绳套装。
- 排除：普通Y形、单片软胸垫、重型战术背心、康复吊带、宠物包、单独牵引绳和项圈。

先判断整款版型，再判断辅助功能；不能因普通胸背带有提手或反光就归入马鞍型。
