# 提示词模板与示例（Prompt Recipes）

> 直接复制给 AI 编程工具（TRAE / Cursor / Claude 等）使用。先大后小：先跑通核心功能，再调细节。

## 一、万能提示词模板（填空式）

```
帮我做一个微信小程序。
功能是：[一句话说清解决什么问题，如"日常记账"]
用户输入：[需要填什么，如"金额、分类、备注"]
点击 [按钮/动作] 后显示：[结果，如"本月总支出和分类占比图表"]
数据存储在：[本地 / 云开发数据库]
界面风格要求：[简洁 / 文艺 / 科技感]，主色调 [颜色或色值]
```

> 提示：模板也可以先让 AI 帮你填，再去完善。生成初版后，用"把某某功能改一下 / 界面颜色换成某某色"逐条微调。

## 二、去"AI 味"两句提示词（生成后追加）

```
1. 不要用紫色系大面积配色，整体配色克制、专业。
2. 不要用 Emoji 当图标；底部导航栏图标用图片文件（可从 iconfont.cn 取 SVG 给我配置）。
```

## 三、各类型小程序示例

### 记账本
```
帮我做一个微信小程序，功能是简易记账本，用户可以记录每日支出，选择分类（餐饮/交通/购物/其他），
输入金额和备注，首页显示本月总支出和按分类的支出占比图表。数据存储在本地。界面风格简洁，主色调用白色。
```

### BMI 计算器
```
帮我做一个微信小程序，功能是 BMI 计算器，用户输入身高（厘米）和体重（公斤），
点击计算按钮后显示 BMI 数值和对应的健康区间（偏瘦/正常/偏胖/肥胖）。
```

### 房贷计算器
```
帮我做一个微信小程序，功能是房贷计算器，用户输入贷款总额、贷款年限、年利率，
计算等额本息和等额本金两种方式的月供金额和总利息，结果并排显示方便对比。
```

### 每日名言
```
帮我做一个微信小程序，功能是每日一句名言展示，每天自动更换一条名言，
用户可以点击复制分享给朋友，背景用渐变色，字体用衬线体，整体风格简洁文艺。
```

### 快递查询
```
帮我做一个微信小程序，功能是快递查询，用户输入快递单号，自动识别快递公司，
显示物流轨迹列表（时间+状态+位置），支持历史查询记录。
```

### 中英夹杂阅读（带云开发，企业资质）
```
角色：你是 10 年经验全栈工程师，精通微信小程序原生开发（WXML/WXSS/JS），擅长极简高级感 UI。
项目：名为「AI短文记单词」的小程序，核心是中英夹杂语境阅读，单词可切换【中英/仅英文/仅中文】。
配色：主色 #3CAB6E，高亮底 #EBF6F0，全局底 #F7F8FA，卡片 #FFFFFF，圆角 16rpx。
需求：阅读页顶部三段切换控件；正文用 [en|zh] 标记，写 parseContent 正则解析；
      单词节点按 displayMode 动态显示；底部上一篇/下一篇。先给模拟数据渲染。
```
