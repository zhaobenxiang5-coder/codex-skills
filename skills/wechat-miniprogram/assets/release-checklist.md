# 上线前检查清单（Release Checklist）

> 上传前花 3 分钟过一遍，可省下 1–3 天重审时间。审核被拒 80% 源于以下 6 类问题。

| # | 检查项 | 快速判断 | 状态 |
| --- | --- | --- | --- |
| 1 | 功能是否正常 | 每个按钮都点一遍，无报错 | ☐ |
| 2 | 页面是否加载 | 每个页面都打开，无空白（弱网也测） | ☐ |
| 3 | 广告位置是否合理 | 不遮挡核心功能、完成任务后才出现 | ☐ |
| 4 | 版本描述是否填写 | 审核员能看懂你改了啥 | ☐ |
| 5 | 类目是否选对 | 工具类选「工具 → 细分类目」 | ☐ |
| 6 | 真机是否预览过 | 手机走完所有功能（非模拟器） | ☐ |

## 逐项要点

**1. 功能正常**
- 从首页点遍所有可点元素；输入正常 + 异常数据（空值/超长/特殊符号）。
- 白屏+报错 → 看控制台红错；数据不显示 → 查 request 合法域名。
- 小技巧：开发者工具「Audits」跑体验评分，< 80 分不建议上传。

**2. 页面加载**
- Network 切 Slow 3G，每页开 ≥3 次确认无偶发空白。
- 首屏 3 秒内须展示内容，否则可能判"性能不合格"。

**3. 广告合理（审核红线）**
- ❌ 广告遮挡关闭按钮 / 诱导点击（"点广告才能用"）/ 首屏弹窗 → 不通过甚至封号。
- 口诀：用户点得到的地方，广告让开。

**4. 版本描述模板**
- 首次发布：`首次提交审核，功能为[XX计算器/XX测试]，无广告遮挡，无诱导分享`
- 修 Bug：`修复了[具体问题]，优化了[XX页面]加载速度`
- 新增功能：`新增[XX功能]，优化了[XX页面]体验`
- 调广告：`调整广告位置：结果页底部增加 Banner，移除首页插屏`

**5. 类目对照（个人安全区：工具 ✅）**
- 房贷计算器 → 工具 → 计算器（不是 金融→理财）
- 性格测试 → 工具 → 信息查询（不是 社交→陌生人交友）
- 记账本 → 工具 → 记账（不是 金融→记账）
- 打卡工具 → 工具 → 备忘录（不是 生活服务→签到）

**6. 真机必测**
- 广告组件、保存图片、分享卡片、微信登录（最易翻车）。
- 首页必测 ×3。
